Historical verification record

The counts and comparisons below describe the October 2 package. Current animation assets and guidance follow the PaperZD decision; see current static verification and the current asset register. Historical measurements are retained, not presented as current runtime evidence.

Documentation, not a prebuilt game

The package documents the full 149-asset register. It does not contain generated .uasset files, finished character art or a playable Unreal project. Suggested graphs, signatures and tuning values have not been compiled or playtested in Unreal.

Direct disk opening was not executed in this environment

The environment’s managed browser blocks URL navigation, including file:// and localhost. That restriction was not changed. Browser checks therefore used injected local page content, not navigation from a file URL. Native localStorage persistence, cross-page persistence and an actual browser ZIP-to-file opening remain unverified here.

The package is designed for direct disk use: all required links and scripts are relative, all referenced files exist, and no fetch, server or online library is required. After extraction, open index.html; then try an asset link and a search. Browser-specific local-file storage may vary. Export checklist progress before moving or replacing the folder.

Architecture and scope review

The main guide preserves the source’s ownership and phase order. The Architecture Notes / Possible Issues page explicitly records source naming inconsistencies, late-phase type references, incomplete test-map bootstrap assumptions, the missing Ability animation enum state, ranged attack hook suggestions, save migration limits and development-cook caveats. These notes do not silently rename registered assets or move folders.

Numeric fixtures are starting test values. New variable types, signatures, helper names and additional graph choices are implementation suggestions. TestPulse, TestHelmet, SliceA/SliceB and the test NPC are not a final content catalog. No crafting, currency, quest framework, respec, dash, double jump, multiplayer or speculative engine migration was promoted into the build requirements.
