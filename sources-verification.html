What is authoritative

The supplied Blueprint_RPG_Architecture_Roadmap.html is the canonical architecture: registered asset identity, parents, placement, phase order and ownership. The supplied master task is the game scope and documentation brief. This manual expands them with proposed field types, signatures, small graph recipes, fixture values and tests, labeled as suggestions rather than silently asserted source facts.

What was and was not verified

Official Epic mechanism pages below were consulted on October 2, 2026. Retrieved pages identify the Unreal Engine 5.8 documentation family. This is not a verification of every behavior/menu in the requested 5.8.3 hotfix, and no Unreal Editor, Blueprint compilation, packaged executable or target-platform save operation was run while creating this manual.

Website file/link/coverage/browser tests are separately recorded in the audit. The game acceptance checkboxes are initially unchecked because they require your actual project. Source E1–E17 references remain preserved inside the unchanged original roadmap; this table is a separate record of mechanism pages consulted for this expansion.
